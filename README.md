# Pulang — Wan 2.1 I2V

Notebook Colab gratis untuk menganimasikan 3 still video pendek "Pulang" (Andra pulang setelah 7 tahun) dengan Wan 2.1 I2V-14B-480P, tanpa Flow/kredit.

## Cara pakai

1. Buka notebook di Google Colab: https://colab.research.google.com/github/eioz21/pulang-wan21/blob/main/Pulang-Wan2.1-I2V.ipynb
2. Pilih Runtime > Change runtime type > T4 GPU.
3. Jalankan semua sel (Runtime > Run all).

## File

- `Pulang-Wan2.1-I2V.ipynb` — notebook Colab Wan 2.1 image-to-video.
- `pulang-stills-wan21.zip` — 3 still image untuk dianimasikan.
